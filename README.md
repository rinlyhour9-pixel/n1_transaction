# N1 Transaction

A driver-first Flutter UI prototype for N1 Logistic. It uses local mock data and Material 3 only, so it is ready to extend with API, maps, and state management later.

## Run

```bash
flutter pub get
flutter run
```

The app starts on a polished driver dashboard and includes Trips, Fuel, Profile, notifications, trip progress, loading confirmation, delivery proof, and fuel request flows.
